# Changes since the last release

## New & Improved

- Added the `TableRowAccessibleText` interface, which a table row may implement to say what an assistive technology
  should call each of its cells. A table names its rows and cells from `CellDataForSort` otherwise, which a row that
  puts an ordering marker ahead of its text would have read out in front of every row.
